Before you begin

This study contains three independent Python programming tasks. You will work in VS Code using the provided HASE repository and GitHub Copilot Chat as your AI assistant.

Set up the repository

  1. Open a terminal and run:
    git clone https://github.com/jofremosegui/HASE2026.git
    cd HASE2026
  2. Open the cloned HASE2026 folder in VS Code (File → Open Folder).
  3. In VS Code, select Terminal → Run Task… → Open HASE Lab. Keep the app running in your browser.

Copilot setup

  1. Use the default GitHub Copilot Chat panel and model. Do not change the model or settings.
  2. Start a new chat for each task. Follow the instructions shown for that task. Do not add any other instructions about response length or verbosity.
  3. Do not edit tests, seed data, study tooling or unrelated files.
  4. Keep the entire interaction in the chat transcript. Use regular Copilot Chat in Ask/chat mode, not Copilot Fusion or workflows that open a separate Requested task panel/form. Do not use separate forms, task panels, or other interfaces to ask questions. Keep all questions and answers in the chat. If something is unclear, make a reasonable assumption and explain it in the chat. Only ask for clarification when it is necessary, and ask directly in a normal chat message.
Important: Keep the code implementation complete and correct. Do not change the task requirements, functionality or implementation quality based on the instructions. Keep the default Copilot model unchanged for all tasks.

Each task has a maximum of 15 minutes. Work through its three subtasks one at a time. Before answering the questions, export that task’s Copilot conversation from VS Code as a JSON file. Then answer the questions without using Copilot, based on your own understanding of the changes.

Data: This page does not inspect your code or AI conversations. Your answers and timing data are stored in this browser until you download the JSON file. At the end, save your code and compress the repository into a ZIP containing your changes, all three exported chat JSON files and the study_data folder. Send the ZIP and the downloaded study-data JSON to the researchers.

Enter the Participant ID written on your post-it. Your assigned schedule will be loaded automatically.
